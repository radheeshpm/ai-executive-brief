1. OpenAI Launches ChatGPT Wallet to Enable Autonomous Agent Checkout

What happened: OpenAI officially introduced ChatGPT Wallet, allowing AI agents across ChatGPT Work, Codex, and dots to execute purchases on behalf of users with user authorization while keeping payment card details obscured, according to OpenAI and reports by Finextra and TechCrunch. Initial availability is rolling out as a limited deployment for U.S. Pro subscribers.

Why it matters: Enabling programmatic checkout workflows transforms frontier models from advisory engines into direct transacting principals, forcing changes to standard digital payments, card-not-present fraud filters, and checkout handshakes.

2. Amazon Threat Intelligence Detects Active Cybercrime Campaigns Run by Autonomous AI Agents

What happened: According to AWS Security, Amazon Threat Intelligence captured malicious activity between October 3 and November 5, 2026, where threat actors operated offensive campaigns using ARTEX, an open-source agentic penetration testing framework. Decoy sensors across Amazon's MadPot network intercepted requests that included agent operating memory targeting simulated enterprise services.

Why it matters: This represents confirmed wild deployment of multi-step, autonomous agentic tool use by cybercriminals, automating scanning, memory management, and exploitation sequences without continuous human supervision.

Banking / delivery action: Update Security Operations Center (SOC) runbooks to recognize programmatic, memory-driven multi-step agent attack patterns and simulate agentic red-team attacks against outward-facing APIs.

Evidence: Official announcement

4. Mior and Skyfall Exploits Compromise AMD SEV-SNP Confidential Computing Environments

What happened: According to The Hacker News, researchers revealed two vulnerabilities—termed Mior and Skyfall—enabling rogue cloud operators with hypervisor control (and BIOS access in Mior's case) to access memory and tamper with signed execution reports inside AMD SEV-SNP confidential virtual machines.

Why it matters: Regulated institutions heavily rely on hardware-enforced trusted execution environments (TEEs) to protect proprietary AI model weights, training data, and customer records during multi-tenant cloud processing.

Banking / delivery action: Assess cloud vendor hardware configurations for AMD SEV-SNP instances hosting sensitive AI workloads and require attestation verification updates from infrastructure providers.
